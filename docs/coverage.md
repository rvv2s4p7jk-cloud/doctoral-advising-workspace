# Requirements coverage

| Agreed requirement | Release implementation | Remaining work |
|---|---|---|
| Candidate / Advisor / own research | Authenticated demo accounts, private own-research record | Real onboarding and invitation assignment |
| Topic and topic changes | Advisor endorsement, university approval, active-topic preservation | Configurable approval chains |
| Chapter milestones | Five chapters, review/revision/acceptance, due dates | Arbitrary chapter structures and document versions |
| Progress forms | Strengths, improvements, behavior evidence, separate ratings, support notes, amendments | Exact institutional form import |
| Check-ins | Dates, next meeting, accomplishments, blockers, agenda, report | Reminders, attendance and cancellation states |
| Research duration | Monthly plan, original/current target, weekly hours, deadline warning | Capacity forecast, approved leave/extension workflows |
| Departments and programs | Labels per workspace; settings snapshots and history | Administrative hierarchy and delegated scope |
| Defense notification | Prepared/sent/acknowledged records, draft wording | Authorized email connector |
| Chair/member feedback | Separate comments, response history, correction verification | Duplicate/conflict reconciliation and configurable reviewers |
| Downloads | Full printable report, CSV, ICS and JSON | DOCX and generated PDF |
| AI notice | Proposed policy, purpose/extent/verification/disclosure log | Formal program-policy approval/version acknowledgments |

This release is deliberately labeled a portfolio demo. All rows should be reassessed before a production deployment.
